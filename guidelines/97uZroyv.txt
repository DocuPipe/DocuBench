This architectural sheet contains three separate schedule tables: DOOR SCHEDULE, ROOM SCHEDULE, and WINDOW SCHEDULE. Extract each as its own array; do not merge or nest them. Read dimensions exactly as printed in feet-and-inches notation (e.g. 2' - 8"), preserving fractions like 5' - 2 1/4". For the room schedule, the floor/wall/ceiling finish columns are blank on this sheet, so leave those fields empty. For the window schedule, set tempered to true only when 'Yes' is printed in the Tempered column, otherwise false. Window type is a fixed vocabulary (FIXED, Casement, AWNING).
